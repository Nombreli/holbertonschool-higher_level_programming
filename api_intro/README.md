# HTTP and HTTPS Basics

## HTTP vs HTTPS
HTTP is an unencrypted protocol used for communication between client and server. HTTPS is the secure version of HTTP that uses SSL/TLS encryption to protect data.

## HTTP Request Structure
- Method (GET, POST, PUT, DELETE)
- URL / Path
- Headers
- Body (optional)

## HTTP Response Structure
- Status Code
- Headers
- Body

## Common HTTP Methods
- GET: Retrieves data
- POST: Sends data to server
- PUT: Updates data
- DELETE: Removes data

## Common HTTP Status Codes
- 200 OK: Request successful
- 201 Created: Resource created
- 301 Moved Permanently: Redirect
- 404 Not Found: Resource missing
- 500 Internal Server Error: Server issue
